# Okoh Divine — Neon Portfolio

A responsive, dark portfolio inspired by the supplied visual reference. Built with plain HTML, CSS and JavaScript; no build step or package installation is required.

## Files
- `index.html` — portfolio content and structure
- `style.css` — responsive styling, neon-green visuals and animations
- `script.js` — mobile menu, scroll progress, reveal effects, cursor glow, interactive role selector, hover-responsive skills orbit and floating arrow controls

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Upload the contents of this folder to your existing portfolio GitHub repository, replacing the old `index.html`, `style.css` and `script.js`.
2. Keep all three files in the repository root.
3. Vercel should automatically redeploy after the GitHub commit.
4. Open the deployed site and test it on desktop and mobile.

## Before publishing
- Review all project descriptions and make sure each project is ready to be public.
- The DivineSocial card is marked “In development” because no public project URL was supplied.
- Check the contact links and email address in `index.html`.
- This is a static portfolio. The email link opens the visitor's email app; it does not store form submissions.

The custom neon-green arrow cursor smoothly follows the mouse on desktop and is automatically disabled on touchscreens.
