# Okoh Divine — Portfolio Website

A responsive, dark-themed personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation, active section links and small interactions

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish
1. Create a GitHub repository (for example `okoh-divine-portfolio`).
2. Upload all three website files, keeping them in the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Or import the repository into Vercel and deploy it as a static site.

## Before publishing
- Review the project descriptions and links. Remove or replace any project that is not ready to be public.
- Add your own LinkedIn profile URL in the LinkedIn link near the top of `index.html`.
- The email link is set to `okohdivine00@gmail.com`; change it if needed.
- No contact form backend is included. The email button opens the visitor's email app.
